Importing Tracking Data

Importing Tracking Data

Section titled “Importing Tracking Data”

The importer accepts these provider datasets:

Dataset Select together Tracking cadence
Canonical CSV One processed .csv Read from the CSV
Opta F24/F7 + TRACAB F24 event XML, F7 roster XML, TRACAB metadata XML, and TRACAB .dat tracking 25 Hz
Opta Match XML + TGV Match XML and the corresponding TGV .txt tracking file 10 Hz or 25 Hz

To import:

  1. In Settings, select Import Tracking Data, or use the button in an empty Pitch Panel.
  2. Select every file belonging to the match in the same file-picker operation. You can instead drag all bundle files, or their containing folder, directly onto the Pitch Panel.
  3. Review the detected format, teams, cadence, and file count before confirming. Do not mix files from different matches; incomplete or mismatched bundles are rejected.
  4. For F24/F7 + TRACAB, review any player-identity choices. High-confidence ID matches are accepted automatically; for each remaining F7 player, choose the matching TRACAB player or explicitly leave that player unmatched.
  5. Confirm the import and wait for parsing, validation, synchronization, and Pitch refresh to finish. You can cancel while the import is still staged.

For Match XML + TGV, cadence is measured from the tracking clocks rather than assumed from the filename. Both 100 ms (10 Hz) and 40 ms (25 Hz) intervals are supported. If the TGV filename includes a 10/25 FPS hint, it must agree with the measured cadence.

When tracking data is already loaded, Pitch asks for confirmation before replacing it. The existing provider dataset remains available if preflight, validation, import, or cancellation prevents activation. Video AI tracking and telestration effects are not replaced. After activation, review the sync offset if the new provider bundle uses a different timeline.

If the same canonical CSV (identified by SHA-256 hash) is already loaded and its stored data passes integrity checks, re-import is skipped to avoid duplicate work.

Sync Parameters

Section titled “Sync Parameters”

Tracking data and video are synchronized using two parameters:

  • Sync Offset: Time offset between tracking data and video (in seconds)
  • Drift Rate: Clock rate difference compensation (default 1.0)
