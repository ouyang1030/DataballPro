时间线

时间线功能

Section titled “时间线功能”
  • 播放头：一条红色竖线，指示当前帧的位置
  • 标注轨道：标注片段默认按 Category 分组。 对于包含具备 Category、Subcategory、Label 值的真实 Tag 按钮的 Code Window 方案， 可使用左侧轨道列表上方的选择器，在 Category 和 Subcategory 行之间切换。 纯文本布局标题不会启用该选择器，Category + Label 方案则保持常规的 Category 视图。 切换行显示方式不会改变标注的标签或帧范围。
  • 标尺：显示帧编号 / 时间刻度
  • 缩放：调整时间线的缩放级别
  • 间隙层：显示追踪数据中的缺口（黄色标记）
  • 重叠检测：可选的蓝色提示条，标记同行及不同行标签的时间重叠。

交互操作

Section titled “交互操作”
  • 点击时间线可跳转到指定帧
  • 拖动标注片段可调整其时间范围
  • 点击某个标注片段可选中它，并在 Details Panel 中查看

将标签边缘吸附到播放头

Section titled “将标签边缘吸附到播放头”

暂停视频，将红色播放头停在目标帧，再拖动标签的左端或右端。边缘靠近红线 （8 px 内）时会自动吸附，并显示“吸附到第 N 帧”。右端向右拖可延长标签， 向标签内部的红线拖可缩短；左端使用相同规则，另一端保持不动。

继续拖离红线超过 12 px 即可脱离，或按住 Alt / Option 临时关闭吸附。 松开鼠标保存，一次拖拽对应一次撤销；Esc 取消。标签至少保留一帧。 整体移动标签、点标注和播放中的边缘调整不吸附。

拖拽中播放头换帧或恢复播放后，本次调整转为普通拖拽；重新拖动可吸附新的暂停帧。 横向滚动时仍可调整边缘；拖拽中改变缩放会取消本次未保存的调整。

更换 label 的 tag

Section titled “更换 label 的 tag”

使用「更换 tag」，可根据 Code Window 中的实际标签，一起修正已有标注的类别、子类别和标签。选中标签后才显示交换图标； 标注尚未结束、处于 Edit 模式或没有可用 tag 时，该按钮禁用。

  1. 在 Code Window 的 Use 模式选中一个已有结束帧的 timeline label。
  2. 点击缩放按钮左侧的交换图标，悬停或聚焦可看到「更换 tag」。 Code Window 未打开时会在工作区展开。
  3. 点击 Code Window 的 tag，或按对应 shortcut。可连续选择，timeline 预览最后一个候选，并显示「未保存」。
  4. 再次点击同一交换图标或按 Enter 保存；按 Esc 则取消。

更换保留 label 的 ID、帧范围、备注和视频片段。保存后才移动到新的分类行， 并保留选中状态。整个更换只产生一步 Undo。未选候选或选回原 tag 后保存， 只退出模式，不写入更改。会话中请先保存或取消再选择另一个 label；拖拽、 调整范围、删除和标注 Undo 暂停。进入布局 Edit 模式或关闭 Code Window 会取消未保存的候选，结束会话后恢复普通打标。独立窗口支持相同点击和 shortcut； 出现「正在连接主窗口」时请等待连接，或点击「重试」。

保存失败时保留未保存的候选；按提示重试、重新选择 tag，或取消后重新选中 label。 文本输入框、弹窗和命令面板优先处理自己的按键。在这些控件之外，单独按 Enter 可保存更换。

检测标签重叠

Section titled “检测标签重叠”

点击「更换标签」与缩放控件之间的图层图标，开启重叠检测；项目中还没有标签时， 该图标不显示。时间刻度顶部的蓝条表示已保存标签的重叠区间，同时包含同行和跨行， 例如「进攻」与「防守」。切换类别／子类别分组不会改变检测结果。首尾相接、点标注和 尚未结束的录制不算重叠。开启后，图标右上角的角标显示重叠区间数量（未发现时为 0）， 点击角标跳到播放头之后的下一处重叠，到最后一处后回到第一处循环。

悬停或聚焦蓝条可查看时间、帧范围与标签。点击蓝条跳到重叠起点并打开列表； 选择列表中的标签，会定位到对应行并选中该标签。缩小时相邻的短蓝条共用一个列表， 可在列表内选择具体区间跳转。更换标签期间，需先保存或取消才能选择另一条标注。

新增、调整范围、更换标签保存成功，以及删除、撤销、重做或 Code Window 同步后， 检测结果自动更新；拖拽或更换标签的未保存预览不参与检测。开关默认关闭，切换项目后 恢复关闭。检测只作提示，不自动修改标签，也不阻止保存。

例如，进攻标签覆盖 12–26 秒，防守标签覆盖 23–37 秒，顶部会在 23–26 秒显示蓝条。 列表显示每条标签的完整路径和当前所在行。更换 tag 后，标签可能移动到另一行， 但由于帧范围不变，蓝条区间也不变。重叠只表示同时发生，需要由你判断是否合理。
